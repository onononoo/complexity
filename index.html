8. language reference

  
let name = expr binds a value. fn name(a, b) = expr defines a function, which is inlined at each call. the last line is the distance to render. p is the sample point (vec3), t is time in seconds, and pi is π.

  
operators: + - * / on floats and vectors; a | b union; a & b intersection; a ~ b subtraction. components are read with .x, .xz and so on. # starts a comment. ctrl+enter recompiles immediately.
